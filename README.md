# 2026-steel-bead
2026年全国大学生电子设计竞赛H题参赛代码
H题的题目描述和任务要求具体要求参考官方网站https://www.nuedc-training.com.cn/
系统整体方案概述：我采用的是双系统来完成的，底盘采用了天猛星（MG3507主控），解决钢珠视觉部分采用的是MaixCan2配合着STM32F103主控芯片
硬件清单（主控芯片 TI MSPM0（天猛星） STM32F103C8T6 、编码器电机（MG513），42张大头闭环步进电机 TB6612、传感器 八路灰度/IMU601 、视觉MaixCan2）
软件开发环境（TI MSPM0（天猛星）使用的是安装了SysConfig插件的Keil5，STM32使用的是Keil5 ）
目录结构说明（Board文件里面是包含了所有延时函数的使用，已经底层的串口收发函数 ；LCD文件里面包含了0.96寸彩屏的底层代码 ；Uart文件里面包含了八路灰度传感器，编码器电机，PID算法，imu601陀螺仪，和VOFA+上位机的代码）
编译和烧录方法：TI MSPM0（天猛星）使用Xds110 ;STM32F103C8T6使用了ST-link
成果展示（第五问的效果：【2026年全国大学生电子设计大赛H题-哔哩哔哩】 https://b23.tv/FSnygKE）
